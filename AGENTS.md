AI AND LLM ARE FORBIDDEN!!!
===========================

This project doesn't accept code or documentation generated by LLMs or any other forms of generative AI. We don't accept code or bug reports which have been reviewed or analyzed by AI. Do not use AI in any way, shape, or form when submitting to this repository.

Please don't submit pull requests based on generative AI output, and don't use AI auto completion when you write pull requests.

Additionally, don't use LLMs to create pull requests or issues. Write them yourself, in English, even if your English is bad.

Any pull request to this project requires you to confirm that you are the author and that you are contributing your changes under the GNU GPL v2 license.

[Here are some reasons to reject LLMs](https://codeberg.org/ethical-foss/ai-free-foss-alternatives/src/branch/main/why_not_llms.md)
